# Bee Swarm Simulator History

Browse Bee Swarm Simulator updates and community events from 2018 onward. Click or tap a date to see what happened.

**[Open the timeline](https://loomyre.github.io/BSSHistory/)**

The timeline includes updates, milestones, incidents, and exploits. Each entry shows details, artwork, and sources where available. Drag or scroll through dates on desktop, or swipe on mobile.

The site runs from `index.html` and can be hosted on GitHub Pages without a build step.

## Contributing

Corrections and missing events are welcome. Please include a source for historical claims, especially disputed events.
